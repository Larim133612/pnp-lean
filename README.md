# pnp-lean

Lean 4 + Mathlib formalization work toward circuit lower bounds, in the context of P vs NP.

**Honest status:** this repository does *not* prove P ≠ NP. It formalizes known,
classical lower bounds as verified building blocks. Every theorem here builds with
no `sorry` and depends only on Lean's standard axioms
(`propext`, `Classical.choice`, `Quot.sound`); CI checks this.

## Contents

| File | Result |
|---|---|
| `Pnp/Circuits/Basic.lean` | Boolean circuits (fan-in 2, full binary basis). **Shannon (1949):** for `n ≥ 5`, some `f : {0,1}ⁿ → {0,1}` has no circuit with `≤ 2ⁿ/(10n)` gates (`shannon_lower_bound`). |
| `Pnp/Formulas/Khrapchenko.lean` | De Morgan formulas. **Khrapchenko (1971):** if `F` is 1 on `A`, 0 on `B`, then `|E(A,B)|² ≤ L(F)·|A|·|B|` (`khrapchenko`). Corollary: every formula for PARITY on `n ≥ 1` bits has `≥ n²` leaves (`parity_formula_lower_bound`). |
| `Pnp/Monotone/Sunflower.lean` | **Erdős–Rado sunflower lemma (1960):** a family of sets of size `≤ ℓ` with more than `ℓ!(p-1)^ℓ` members contains a sunflower with `p` petals (`erdos_rado`). Engine of Razborov's method (M3). |
| `Pnp/Monotone/Circuit.lean` | Monotone circuits (AND/OR straight-line programs); they compute monotone functions (`MCircuit.eval_monotone`). **Abstract approximation method:** if each approximate gate step makes `≤ dPos` positive / `≤ dNeg` negative errors and inputs are exact, the output approximator errs on `≤ s·dPos` positive and `≤ s·dNeg` negative tests (`approximation_method`). |
| `Pnp/Monotone/Clique.lean` | CLIQUE(m,k) on graph inputs; positive tests (k-cliques) and negative tests (complete (k−1)-partite graphs of colourings, `not_hasClique_colorGraph` by pigeonhole); clique-indicator approximators; the approximation method specialised to CLIQUE (`clique_approximation`). |
| `Pnp/Monotone/Pluck.lean` | Plucking sunflowers (cores of size `≤ 1` normalised to `∅`). **Key counting lemma:** if sets `P i` (`i ∈ ι`, size `≤ ℓ`) pairwise meet inside `C`, at most `(ℓ²)^{|ι|}·r^{m-|ι|}` colourings `Fin m → Fin r` are injective on `C` but on no `P i` (`card_petal_collisions`). Plucking only shrinks sets (no positive errors), keeps sizes, reaches `≤ L` members for `L ≥ ℓ!(p-1)^ℓ` (`card_pluck_le`), and `n` steps cost `≤ n·(ℓ²)^p·r^{m-p}` negative errors (`card_negErr_pluck`). |
| `Pnp/Monotone/Razborov.lean` | Alon–Boppana approximate gates (`abAop`): per-gate errors `≤ L²·C(m-ℓ-1,k-ℓ-1)` positive (`abAop_posErr`) and `≤ L²·(ℓ²)^p·(k-1)^{m-p}` negative (`abAop_negErr`). **Razborov's theorem (Alon–Boppana form):** a monotone circuit with `s` gates computing CLIQUE(m,k) satisfies `C(m,k) ≤ s·L²·C(m-ℓ-1,k-ℓ-1)` or `(k-1)^m - ℓ²(k-1)^{m-1} ≤ s·L²·(ℓ²)^p·(k-1)^{m-p}`, `L = ℓ!(p-1)^ℓ` (`razborov_alon_boppana`). |
| `Pnp/Monotone/Construct.lean` | **Non-vacuity:** monotone formulas compile to monotone circuits (`MForm.exists_circuit`); for `2 ≤ k ≤ m` the DNF `⋁_{|K|=k} ⋀_{u<v∈K} x_{uv}` gives a monotone circuit computing CLIQUE(m,k) via the standard labelling (`exists_computesClique`, `exists_offDiag_computesClique`). (For `k ≤ 1` or `k > m` CLIQUE is constant and no constant-free monotone circuit computes it.) |
| `Pnp/Monotone/LowerBound.lean` | **Explicit superpolynomial bound (M3e):** with `K ℓ = 2ℓ⁶+1`, `M ℓ = 2ℓ⁴·K ℓ + ℓ ≤ 7ℓ¹⁰` and `p = ℓ+1`, every monotone circuit computing CLIQUE(M ℓ, K ℓ) (any off-diagonal labelling) has `≥ 2^ℓ` gates for `ℓ ≥ 2` (`monotone_clique_lower_bound`), i.e. size `2^{Ω(m^{1/10})}` in the number `m` of vertices; such circuits exist (`exists_circuit_clique_MK`); no bound `s ≤ c·m^d` holds for all `ℓ` (`monotone_clique_superpolynomial`). |
| `Pnp/AC0/Formula.lean`, `Pnp/AC0/Approx.lean` | AC⁰ formulas (literal leaves, unbounded fan-in AND/OR over `Fin t → Formula`; `size` = number of gates, `depth` = gates on longest path). **Razborov–Smolensky approximation (M4a):** for every `ℓ`, a formula `F` agrees with a polynomial over `𝔽₃` of total degree `≤ (2ℓ)^{depth F}` on all 0/1 inputs outside a set `E` with `|E|·2^ℓ ≤ size F·2ⁿ` (`ac0_approx`). Core: a nonzero vector has vanishing subset sum for at most half of all subsets (`card_sum_eq_zero_mul_two_le`), then double counting picks a good OR approximant (`or_step`); no probability. |
| `Pnp/AC0/Smolensky.lean` | **Smolensky's lemma (M4b):** if `P` over `𝔽₃` has total degree `≤ D`, it agrees with PARITY on at most `#{T ⊆ [n] : |T| ≤ n/2 + D} = ∑_{i ≤ n/2+D} C(n,i)` points of `{0,1}ⁿ` (`smolensky`, `smolensky_choose`); hence `2·|agree| ≤ 2ⁿ + 2(D+1)·C(n,⌊n/2⌋)` (`smolensky_tail`). Proof via `yᵢ = 1 + xᵢ ∈ {±1}`, multilinearisation (`yᵢ² = 1`), interpolation, and `3^|G| ≤ 3^#{small sets}`. |
| `Pnp/AC0/Parity.lean` | **PARITY ∉ AC⁰ (M4c).** Central binomial bound `C(n,⌊n/2⌋)²·(n+1) ≤ 4ⁿ` (`choose_half_sq_mul_le`). A formula `F` computing PARITY on `n` bits has `2^ℓ ≤ 4·size F` whenever `16·((2ℓ)^{depth F}+1)² ≤ n+1` (`parity_ac0_lower_bound`; depth-`≤ d` form `parity_ac0_lower_bound_of_depth_le`), i.e. size `2^{Ω(n^{1/(2d)})}`. For fixed `d, c, k`, for all large `n` every depth-`≤ d` formula for PARITY has `> c·n^k` gates (`parity_not_in_AC0`). Non-vacuity: a depth-`≤ 2` DNF computes PARITY for every `n` (`exists_parity_formula`). |
| `Pnp/AC0/Circuit.lean` | **AC⁰ circuits (M6).** Unbounded fan-in AND/OR circuits (DAGs, straight-line programs over literals). A circuit of size `s` and depth `d` unfolds to an equivalent formula of depth `d` and size `≤ s^d` (`Circuit.exists_formula`). Hence a depth-`d` circuit for PARITY has `2^ℓ ≤ 4·s^d` whenever `16·((2ℓ)^d+1)² ≤ n+1` (`parity_ac0_circuit_lower_bound`), and for fixed `d, c, k` every depth-`≤ d` circuit for PARITY eventually has `> c·n^k` gates (`parity_not_in_AC0_circuits`). Non-vacuity: a depth-2 circuit computes PARITY (`exists_parity_circuit`). |
| `Pnp/Circuits/GateElim.lean` | **Gate elimination (M7).** A function depending on all `n` variables needs `≥ n − 1` gates (`le_size_of_depends`). **Schnorr (1974):** every B₂ circuit computing the threshold function `Th₂` ("at least two ones") on `n ≥ 2` variables has `≥ 2n − 3` gates (`th2_lower_bound`, `not_hasCircuitOfSize_th2`); proof by restricting variables to 0 and removing ≥ 2 gates per step. Non-vacuity: `Th₂` has a circuit with `≤ 3n + 2` gates (`th2_hasCircuitOfSize`). |
| `Pnp/Circuits/Schnorr.lean` | **Schnorr's class Q²,³ (M12a).** General theorem `q23_lower_bound`: if `f` has, on every "good" restriction with `m` free variables, dependence on each free variable (`m ≥ 2`), three pairwise distinct subfunctions for every pair of free variables (`m ≥ 3`), and every free variable can be fixed to some constant keeping the restriction good, then every B₂ circuit for `f` has `≥ 2n − 3` gates. Reduction lemmas for symmetric functions (`sym_dep`, `sym_three`). Instances: `MOD₃` with any residue (`mod3_lower_bound`) and `Th₂` re-derived (`th2_lower_bound'`). PARITY is not in Q²,³ (it has `n − 1`-gate circuits). |
| `Pnp/Circuits/U2.lean` | **PARITY over U₂ (M13).** U₂ = all binary gates except XOR/XNOR. **Schnorr (1974):** every U₂ circuit computing PARITY on `n ≥ 1` variables has `≥ 3(n − 1)` gates (`parity_u2_lower_bound`); gate elimination fixing one variable removes 3 gates (the first gate, another reader of the fixed variable, and a reader of the first gate). Tight: a chain of `n − 1` XORs built from 3 U₂ gates each (`parity_u2_hasCircuit`, `parity_u2_complexity`). |
| `Pnp/Circuits/Multi.lean` | Multi-output circuits; sequential composition, iteration (`T` copies of a size-`s` map cost `T·s`), parallel combination; every function of `k` fixed input bits has a circuit of size `4·2^k` (`hasCircuitOfSize_junta`); hence a map whose every output bit depends on `k` input bits has size `≤ m·4·2^k` (`hasMCircuitOfSize_local`). |
| `Pnp/Circuits/Majority.lean` | Majority of `m` bits with `O(m²)` gates (threshold dynamic program, `hasCircuitOfSize_maj`); the Goldreich–Levin inverter shape `glInv` (majority of `B(y, c_{ij}) ⊕ d_j`) with `glInvSize n m sB` gates (`hasMCircuitOfSize_glInv`, `glInvSize_le`). |
| `Pnp/PPoly/TM2Local.lean` | Locality of Mathlib's two-stack (TM2) machines: one step replaces each stack `S k` by `W k ++ drop (P k) (S k)`, where `W, P` and the new control state depend only on the top `depth` cells (`stepAux_eq_nf`, `stk_getElem?_stepAux`); stack lengths grow by `≤ D` per step; reachable stack symbols lie in a finite set `A tm k` even when the stack alphabet type is infinite (`A_finite`, `iterate_step'_stkInA`); a run within time `T` is `T` iterations of a total step (`outputsInTime_step'`). |
| `Pnp/PPoly/Encode.lean`, `Pnp/PPoly/Simulate.lean` | One-hot encoding of strings and configurations (stacks as arrays of length `n + T·D + 1`); the encoded step is a local map; a machine running in polynomial time `time` is simulated by circuits of size given by an explicit polynomial (`simulate`; `simulateOn` only needs correct runs on a set `S` of inputs). |
| `Pnp/PPoly/PPoly.lean`, `Pnp/PPoly/NonVacuity.lean` | **P ⊆ P/poly (M5).** `InPPoly L`: for every `n ≥ 1` a circuit of size `≤ p(n)` decides `L` on one-hot encoded strings of length `n`. Every language in the upstream class P (`InPolynomialTime`, Mathlib `TM2ComputableInPolyTime`) is in P/poly (`inPPoly_of_inPolynomialTime`). **Connection to the official statement:** if some language in the upstream NP has no polynomial-size circuits, then `Millennium.ClayPVersusNP.Formulations.NegativeBranch` (P ≠ NP) holds (`negativeBranch_of_not_inPPoly`). This is conditional: proving such a lower bound for an NP language is open. Non-vacuity (`NonVacuity.lean`): over every alphabet with two symbols some language is not in P/poly (`exists_not_inPPoly`, Shannon counting), and the trivial language is (`inPPoly_true`). |
| `Pnp/Oracle/Machine.lean`, `Pnp/Oracle/Locality.lean` | **Oracle stack machines (M8).** Our own concrete model: a program is a finite list of `push`/`pop`/`query`/`halt` instructions on unboundedly many bit stacks; `query k` asks whether the content of stack `k` lies in the oracle (cost 1 step; writing the query costs 1 step per bit). Relativized classes `P O` and `NP O` with time `(n+2)^k` (certificates of length `≤ (n+2)^k` on stack 1). A run of `t` steps makes `≤ t` queries and depends only on the oracle on those queries (`queries_length_le`, `runFor_congr`). |
| `Pnp/Oracle/PSubsetNP.lean` | `P O ⊆ NP O` for every oracle (`P_subset_NP`), by renaming stacks so the certificate is never touched. |
| `Pnp/Oracle/BGS.lean` | **Baker–Gill–Solovay, oracle B:** `L_B = {x : ∃ w ∈ B, |w| = |x|}` is in `NP^B` for every `B` (`LB_mem_NP`, explicit 6-instruction verifier), and by diagonalisation over all (program, exponent) pairs some `B` has `L_B ∉ P^B` (`LB_not_mem_P`); hence `P^B ⊊ NP^B` (`exists_oracle_P_ssubset_NP`). |
| `Pnp/Oracle/Combinators.lean`, `Pnp/Oracle/BGSA.lean` | **Baker–Gill–Solovay, oracle A:** a self-referential oracle defined by well-founded recursion on string length, `code(i,x,T) ∈ A` iff verifier `i` accepts `x` with oracle `A` (padding `T` makes all its queries shorter than the code). An explicit deterministic machine writes `code(i, x, (|x|+2)^{k+1})` (nested counting loops) and queries it in time `(n+2)^{3(k+1)+i+11}` (`queryProg_run`, `queryTime_le`), so `NP^A ⊆ P^A` (`exists_oracle_NP_subset_P`). |
| `Pnp/Oracle/Relativization.lean` | **Relativization barrier:** `∃ A, P^A = NP^A` and `∃ B, P^B ⊊ NP^B` (`baker_gill_solovay`); hence neither `P^O = NP^O` nor `P^O ≠ NP^O` holds for all oracles (`relativization_barrier`). Caveat: this is a theorem about our oracle model; the model is not yet formally proved equivalent to the upstream (unrelativized) TM2 classes (proved: `P ∅ = P` and `NP ∅ = NP` over `Bool`, see `Official.lean`, `OfficialP.lean`, `OfficialNP.lean`, `NPEquiv.lean`), and "a proof technique relativizes" is a meta-level notion that is not itself formalized. |
| `Pnp/Oracle/Official.lean` | **Bridge to the official class P (M11).** With the empty oracle, our model is no stronger than the official one: every language in `P ∅` is in the upstream class P over the alphabet `Bool` (`Pnp.Relativize.Official.inPolynomialTime_of_mem_P_empty`). Proof: each program is compiled into a Mathlib `FinTM2` (one instruction = one TM2 step, empty-oracle queries answer "no", a final cleanup phase empties the work stacks), running in time `T + w·(|x|+T+1)` with `T = (|x|+2)^k`. The converse inclusion is `OfficialP.lean`. |
| `Pnp/Oracle/Truncate.lean`, `Pnp/Oracle/OfficialNP.lean` | **Bridge to the official class NP (M11b).** With the empty oracle, every language in `NP ∅` is in the upstream class NP over the alphabet `Bool` (`Pnp.Relativize.OfficialNP.inNP_of_mem_NP_empty`). The checking relation is "the verifier accepts `(x, y)` within `(|x|+2)^k` steps" (answers hard-wired for the three inputs of length `≤ 1`, whose official certificates have length `≤ 1`). The compiled Mathlib `FinTM2` splits `x#y` into two stacks, builds a clock of exactly `(|x|+2)^k` marks with the nested counting loops `Comb.pad` (reused from M8), runs the verifier popping one clock mark per instruction (so it halts in polynomial time on every certificate) and empties its work stacks. Certificates longer than the time bound are cut by `runFor_take` (a run of `t` steps only reads the first `t` certificate bits). |
| `Pnp/Oracle/FromTM2.lean`, `Pnp/Oracle/OfficialP.lean` | **Official P ⊆ `P ∅` and the bridge (M11c).** Any Mathlib `FinTM2` with input alphabet `≃ Bool` is compiled into a stack program (`FromTM2.prog`): the finitely many reachable symbols of each stack (`A tm k`) are written in truncated unary (the input stack uses `[true]`/`[false]`, so the raw input is already encoded), and the finite control gets one instruction per state. One TM2 step costs at most `Dm·B` program steps (`FromTM2.sim_step'`), so official P ⊆ `P ∅` (`OfficialP.mem_P_empty_of_inPolynomialTime`) and `P ∅` *equals* the official P over `Bool` (`mem_P_empty_iff`). **Bridge:** if some language is in our `NP ∅` but not in our `P ∅`, the official `NegativeBranch` (P ≠ NP) holds (`OfficialP.negativeBranch_of_NP_not_subset_P`). This only transfers the problem: proving such a separation is still open. |
| `Pnp/Oracle/Shift.lean`, `Pnp/Oracle/FromNP.lean`, `Pnp/Oracle/NPEquiv.lean` | **Official NP ⊆ `NP ∅` (M11d).** For an official NP language (certificate alphabet `Γ₁` any finite type, checking relation decided by a Mathlib `FinTM2` on the pair encoding `x # y`), our verifier `NPEquiv`/`FromNP.V` is the concatenation (via `Shift.reloc`, `Reach.embed`) of: moving certificate and input to scratch stacks while counting `\|x\|`; a clock of `\|x\|^k` marks (`Comb.pad`); decoding the binary certificate as truncated-unary codes of `Γ₁`-symbols, one clock mark per symbol (malformed or too long ⇒ reject, `FromNP.decode`); building the official input `x # y` on stack `0`; and the compiled official machine (`FromTM2.prog` with an offset layout). `FromNP.outcome`: every run halts, and acceptance means the certificate encodes some `y`, `\|y\| ≤ \|x\|^k`, that the official machine accepts. Hence `NPEquiv.mem_NP_empty_of_inNP`, `NP ∅` *equals* the official NP over `Bool` (`mem_NP_empty_iff`), and the official `P = NP` question over `Bool` is exactly `P ∅ = NP ∅` (`official_P_eq_NP_bool_iff`). |
| `Pnp/NaturalProofs/Barrier.lean` | **Natural proofs barrier (Razborov–Rudich):** properties `Γ n` of `n`-variable Boolean functions that are *constructive* (decided from the `2ⁿ`-bit truth table by circuits of size `poly(2ⁿ)`), *large* (density `≥ 1/poly(2ⁿ)`) and *useful against P/poly* (for every polynomial `p`, infinitely often no member has a `p(n)`-gate circuit). A constructive, large, useful property breaks every pseudorandom function family in P/poly (`natural_proofs_barrier`); contrapositive `no_natural_property_of_secure_prf`; explicit one-length version `natural_breaks_prf` (the deciding circuit itself is a distinguisher with advantage `≥` the density). Security is the Razborov–Rudich notion: distinguishers of size `poly(2ⁿ)` reading the whole truth table have advantage `< 1/poly(2ⁿ)`. Caveats: the existence of secure PRFs is an explicit hypothesis (believed, unproven); "a proof naturalizes" is a meta-level notion that is not formalized. |
| `Pnp/NaturalProofs/NonVacuity.lean` | Sanity checks: "all functions" is constructive and large; Shannon's property "no circuit with `2ⁿ/(10n)` gates" is large (density `≥ 1/2`) and useful against P/poly (`shannon_large_useful`). So the barrier is really about constructivity. |
| `Pnp/NaturalProofs/GGM.lean` | **GGM construction (M14): secure PRG ⇒ secure PRF.** From a length-doubling generator `s ↦ G₀(s)G₁(s)`, the GGM function `x ↦ bit₀(G_{x_{n-1}}(⋯G_{x_0}(k)))`. Hybrid lemma for independent samples (`hybrid`); concrete reduction `ggm_reduction` (a truth-table distinguisher of size `cT` and advantage `α` gives a generator distinguisher of size `2ⁿ(n·sG+1)+cT` and advantage `≥ α/2ⁿ`); GGM circuits of polynomial size (`hasCircuit_ggm`); asymptotic `PRG.ggmFamily_secure`, `PRG.ggmFamily_inPPoly`; corollary `no_natural_property_of_secure_prg`. Security of the generator (`PRG.SecureAlong μ`: size-`poly(2ⁿ)` distinguishers at seed length `μ(n)` have advantage `< 1/poly(2ⁿ)`) is an explicit hypothesis. Also fixes `PRFamily.InPPoly` to quantify over `n ≥ 1` (no circuit exists for `0` inputs in this model, so the old condition was unsatisfiable); `ggmFamily_id_inPPoly` checks it is now satisfiable. |
| `Pnp/NaturalProofs/GoldreichLevin.lean` | **Goldreich–Levin hardcore bit (M16).** Subset sums `r_S = ⊕_{a∈S} r_a` of independent uniform strings are uniform and pairwise independent (`ex_rsum`, `ex_rsum_mul`); Chebyshev for the majority vote (`prob_vote_fail`); concrete theorem `goldreich_levin`: a size-`sB` circuit predicting `⟨x,r⟩` from `(f x, r)` with probability `≥ 1/2+ε` gives, for `(2^l−1)ε² ≥ 2n`, a circuit with `glInvSize n (2^l−1) sB = O(n·4^l·(n+sB))` gates recovering `x` from `f x` with probability `≥ ε/2^{l+2}` (random strings and guesses fixed non-uniformly, so the inverter never evaluates `f`). Asymptotic `OWF.hardcore_ip`: if `f` is one-way against size-`poly(2ⁿ)` circuits (`OWF.HardAlong μ`, an explicit hypothesis), the inner product is a hardcore predicate in the same regime. |
| `Pnp/NaturalProofs/BMCircuits.lean`, `Pnp/NaturalProofs/BlumMicali.lean` | **PRGs from one-way permutations (M17, Blum–Micali–Yao).** Generator `bmOut f T (x, r) = (⟨x,r⟩, ⟨f x,r⟩, …, ⟨f^{T−1}x,r⟩, f^T x, r)` with polynomial circuits (`hasMCircuitOfSize_bmGen`, `hasMCircuitOfSize_bmHyb`). Hybrid argument (`exists_step`) and Yao's distinguisher-to-predictor step (`yao`) give the concrete `bm_reduction`: a size-`sD` test with advantage `α` against the generator yields a predictor for `⟨z,r⟩` from `(f z, r)` with success `≥ 1/2 + α/T`. Asymptotically (`OWF.bmPRG`, length doubling at every seed length): `OWF.bmPRG_secure` — a family of permutations in P/poly that is one-way along `ν` (`OWF.HardAlong ν`) gives `PRG.SecureAlong (2ν)`; hence `no_natural_property_of_owp`: one-way permutations (in the `poly(2ⁿ)` regime) rule out natural proofs against P/poly. `hardcore_at` (in GoldreichLevin.lean) is the per-length form of Goldreich–Levin used here. |
| `Pnp/Derandomization/NisanWigderson.lean` | **Nisan–Wigderson generator (M18, hardness vs. randomness).** For `f : {0,1}^m → {0,1}` and a design `S₁,…,S_L ⊆ [d]` (`Design d m L a`: `|Sᵢ| = m`, `|Sᵢ ∩ Sⱼ| ≤ a`), `nw f S z = (f(z|S₁), …, f(z|S_L))`. `nw_reduction`: a size-`sD` test with advantage `α` yields a predictor for `f` with `L·4·2^a + sD + 1` gates and success `≥ 1/2 + α/L` (hybrids, Yao, and the design property: outside `Sⱼ` fixed, every other output is a junta of `≤ a` bits). `nw_secure`: if `f` is `(L·4·2^a + sD + 1, ε)`-hard on average (`AvgHard`), every size-`sD` test has advantage `≤ L·ε`. `polyDesign`: over a finite field with `q` elements, graphs of polynomials of degree `< k` give `q^k` sets of size `q` in `q²` points, pairwise intersections `≤ k−1`; `nw_poly_secure` combines them (seed `q²` bits, output `q^k` bits). Average-case hardness of `f` is a hypothesis. |
| `Pnp/Derandomization/HardFunctions.lean` | **Average-case hard functions exist (M19).** `card_agree_le`: Hoeffding/Chernoff bound proved elementarily (exponential moments, `cosh x ≤ exp(x²/2)`): at most `2^N·exp(−2ε²N)` functions on an `N`-element set agree with a fixed `g` on more than `1/2 + ε`. `exists_avgHard`: if `circCount m s · exp(−2ε²2^m) < 1` then some `f : {0,1}^m → {0,1}` is `AvgHard f s ε`; `exists_avgHard_explicit`: for `m = 8k`, circuits with `2^(m/4)` gates and `ε = 2^(−m/8)`. `exists_nw_secure`: hence the hypothesis of M18 is satisfiable, and Nisan–Wigderson generators that fool small circuits exist non-uniformly (with a non-explicit `f`; this is not a derandomization of BPP). |
| `Pnp/Derandomization/Adleman.lean` | **Adleman's theorem, circuit form of BPP ⊆ P/poly (M20).** `ex_pi_prod` (independent copies), `prob_vote_wrong_le`: majority of `2j` independent runs of a circuit with error `≤ 1/3` errs with probability `≤ (8/9)^j` (exponential moments). `adleman`: if `C(x, r)` with `s` gates errs with probability `≤ 1/3` on every `x ∈ {0,1}^n`, then `f` has a deterministic circuit with `k(s+2) + majSize k` gates, `k = 12(n+1)` (union bound over inputs, random strings hard-wired). |
| `Pnp/Derandomization/BPP.lean` | **Official-style `BPP` and `BPP ⊆ P/poly` (M21).** `InBPP L`: some polynomial-time checking relation `R` (official Mathlib `TM2` machine on the Cook pair encoding `w#r`, exactly as for the official `NP`) satisfies `R w r ↔ L w` for all but `≤ 1/3` of the random strings `r ∈ {0,1}^{|w|^k}`. `inPPoly_of_inBPP`: every such language is in `P/poly` (circuit simulation of the verifier via `Pnp.PPoly.simulateOn`, a re-encoding circuit `encE`, then `adleman`). `not_inBPP_of_not_inPPoly`. |
| `Pnp/Derandomization/Lautemann.lean` | **Sipser–Gács–Lautemann, circuit form of BPP ⊆ Σ₂ ∩ Π₂ (M22).** Lautemann's shifting argument: `exists_cover` (if `S ⊆ {0,1}^ℓ` misses ≤ ε and `2^ℓ ε^k < 1`, some `k` shifts `S ⊕ tᵢ` cover the cube; union bound over `y`, `prob_forall_pi`, translation invariance `prob_vxor`) and `no_cover` (if `|S| ≤ ε 2^ℓ` and `kε < 1`, no `k` shifts cover). `lautemann_iff`: `f x = 1 ↔ ∃ t ∀ y ∃ i, C(x, tᵢ ⊕ y) = 1`. `sipser_gacs_lautemann`: the inner predicate is a circuit with `k((n+ℓ)·16 + s + 1)` gates on input `x ++ u ++ y` (`u` = the `k` shifts, flattened); `sipser_gacs_lautemann_compl` (Π₂ side, for `¬f`); `sipser_gacs_lautemann_third`: from error `1/3`, after amplification by majority of `sglReps ℓ = 24(24ℓ+1)` copies (`hasCircuitOfSize_ampl`). Circuit (non-uniform) form only; the official TM class `Σ₂ᴾ` is not connected. |
| `Pnp/Derandomization/ValiantVazirani.lean` | **Valiant–Vazirani isolation lemma (M23).** Random affine hash `h(x) = (⟨x, aᵢ⟩ ⊕ bᵢ)ᵢ` over GF(2) with `m` rows: `prob_hashZero` (`Pr[h x = 0] = 2^{-m}`) and `prob_hashZero_pair` (`= 4^{-m}` for `x ≠ x'`, via `prob_ip_false`: `⟨d, a⟩` is unbiased for `d ≠ 0`). `isolation`: if `2^j ≤ |S| ≤ 2^{j+1}` and `m = j+2`, exactly one element of `S` survives with probability `≥ 1/8` (inclusion–exclusion lower bound, `ind_unique_ge`). `valiant_vazirani`: for a circuit `C` with `s` gates, `C' = C ∧ (h = 0)` has `s + m(2n+5)` gates; unsatisfiable `C` stays unsatisfiable, satisfiable `C` gets a unique solution with probability `≥ 1/8` for some `m ≤ n+2` (circuit form of the randomized reduction SAT → Unique-SAT). |
| `Pnp/TM2/Projection.lean` | **Deciders as verifiers in the official machine model (M24).** `projComp`: from a Mathlib `TM2ComputableInPolyTime` machine for `f : List α → δ`, a hand-built composite machine (`projTM`: two extra stacks; phase 1 strips `w#y` keeping `w` reversed, phase 2 moves `w` onto the original input stack, phase 3 runs the lifted original program, `liftS` / `stepAux_liftS`) computes `(w, y) ↦ f w` on the Cook pair encoding in time `time(|w|) + |w| + |w#y| + 2`. Hence `deciderAsVerifier` (the upstream hypothesis `ClayPVersusNP.Support.DeciderAsVerifier`) and `p_subset_np`: the official `P ⊆ NP` **without** the upstream composition-closure hypothesis. |
| `Pnp/Derandomization/PSubsetBPP.lean` | **`P ⊆ BPP` for the official classes (M24).** `inBPP_of_inPolynomialTime` (error probability 0, via `polynomialTimeCheckingRelation_fst`), so `P ⊆ BPP ⊆ P/poly` officially (alphabet assumed non-empty). |
| `Pnp/TM2/Compose.lean` | **Polynomial-time `TM2` machines compose (M25).** `comp`: `TM2ComputableInPolyTime ea eb f → TM2ComputableInPolyTime eb ec g → TM2ComputableInPolyTime ea ec (g ∘ f)` for arbitrary encodings (Mathlib's `proof_wanted TM2ComputableInPolyTime.comp`). The composite machine `compTM` runs `M₁` (its `halt` becomes a jump), copies `M₁`'s output onto `M₂`'s input stack through a scratch stack, then runs `M₂`. Time bound via short outputs: `length_output_le` (`|f a| ≤ |a| + C·time₁(|a|)`, `C` = max pushes per statement, `size_stepAux`, `size_run`). Corollaries: `polynomialTimeComputableComposition` (the upstream hypothesis), and unconditional `reducible_source_in_p`, `reducible_trans`, `npComplete_transfer`, `clay_iff_hard_direction` (`P = NP ↔ NP ⊆ P`), `clay_of_npComplete_in_p`, `not_inP_of_npComplete`. |
| `Pnp/Algebrization/Extension.lean` | **Algebraic oracles (M10).** An extension `Ã` of an oracle `A` (Aaronson–Wigderson): for every finite field and arity `m` a polynomial of degree `≤ 2` in each variable that equals the indicator of `A` on `{0,1}^m` (`IsExtension`). Fields are the representatives `Fld q = GaloisField p (k+1)` (`q = Nat.pair p k`), which cover every finite field up to isomorphism (`exists_ringEquiv_Fld`; `IsExtension.exists_poly` transports an extension to any finite field `K`; e.g. `card_Fld_four`: 𝔽₄ is included). `Ã` is turned into an ordinary oracle for the stack machines (`toOracle`): the query `encQ q j xs` (binary, self-delimiting; coordinates are codes of field elements) returns bit `j` of the code of `Ã_{q,m}(xs)`; `P^Ã = P (toOracle Ã)`, `NP^Ã = NP (toOracle Ã)`. |
| `Pnp/Algebrization/Interpolation.lean` | **Vanishing multiquadratic polynomials:** for any `t` points `Y ⊆ F^n` (any field), all but at most `t` Boolean points `z` admit a polynomial of degree `≤ 2` in each variable that vanishes on `Y` and is the indicator of `z` on the cube (`exists_vanishing_indicator`; linear algebra, rank–nullity). |
| `Pnp/Algebrization/Collapse.lean` | **`NP^Ã ⊆ P^A` for some `A, Ã`:** the multilinear extension `mle A` is an extension (`isExtension_mle`); a self-referential padded oracle as in the BGS oracle `A`, with verifiers run against `toOracle (mle A)`, gives `NP^Ã ⊆ P^A` (`exists_ext_NPA_subset_P`). (Aaronson–Wigderson use a PSPACE-complete `A`; the statement is the same.) |
| `Pnp/Algebrization/Diagonal.lean` | **`NP^A ⊄ P^Ã` for some `A, Ã`:** diagonalization against all polynomial-time machines that query the extension; at each stage the machine makes `< 2ⁿ` queries, so by the vanishing lemma (union bound over the primes queried) a single Boolean point `z` can be added to `A` with an extension that is `0` at every queried point, hiding the change (`exists_ext_LB_not_mem_PA`, `exists_ext_NP_not_subset_PA`). |
| `Pnp/Algebrization/Barrier.lean` | **Algebrization barrier (Aaronson–Wigderson 2008):** both outcomes occur (`aaronson_wigderson`), so neither the separation `P ≠ NP` nor the collapse `P = NP` algebrizes (`algebrization_barrier`). Extensions range over all finite fields (M15). Caveats: theorems are about our oracle model, which is not formally proved equivalent to the upstream classes; "a proof technique algebrizes" is meta-level and not formalized. |
| `Pnp/Upstream/*.lean` | P vs NP problem statement from [lean-dojo/LeanMillenniumPrizeProblems](https://github.com/lean-dojo/LeanMillenniumPrizeProblems) (Apache-2.0), imports adapted. Target: `Millennium.ClayPVersusNP.Formulations.NegativeBranch`. |

- [x] M1 Shannon counting lower bound
- [x] M2 Khrapchenko: de Morgan formulas for PARITY need `n²` leaves
- [x] M3 Razborov: monotone circuit lower bound for CLIQUE
  - [x] M3a Erdős–Rado sunflower lemma
  - [x] M3b Monotone circuits, test graphs, abstract approximation method
  - [x] M3c Plucking and per-gate error bounds for Alon–Boppana approximators
  - [x] M3d Size inequality for monotone circuits computing CLIQUE
  - [x] M3e Explicit parameters: size `≥ 2^ℓ` for CLIQUE(`~4ℓ¹⁰`, `2ℓ⁶+1`), i.e. `2^{Ω(m^{1/10})}`; non-vacuity
- [x] M4 PARITY ∉ AC⁰
  - [x] M4a AC⁰ formulas are approximated by low-degree `𝔽₃` polynomials
  - [x] M4b Smolensky: degree-`D` `𝔽₃` polynomials agree with PARITY on `≤ ∑_{i ≤ n/2+D} C(n,i)` points
  - [x] M4c PARITY needs size `2^{Ω(n^{1/(2d)})}` at depth `d`; superpolynomial for every fixed depth
- [x] M5 P ⊆ P/poly for the upstream TM2 model, and "NP ⊄ P/poly ⇒ NegativeBranch"
  - [x] M5a multi-output circuits, composition, iteration, local maps
  - [x] M5b locality and finite reachable alphabet of TM2 steps
  - [x] M5c simulation of polynomial-time TM2 machines by polynomial-size circuits
  - [x] M5d non-vacuity: some language is not in P/poly
- [x] M6 PARITY ∉ AC⁰ for circuits (DAGs) via unfolding to formulas of size `≤ s^d`
- [x] M7 Schnorr: `Th₂` needs `2n − 3` gates in B₂ (gate elimination)
- [x] M12 Schnorr's class Q²,³: `2n − 3` for MOD₃ (and `Th₂`) in B₂
- [x] M13 PARITY needs exactly `3(n − 1)` gates over U₂ (B₂ without XOR/XNOR)
- [x] M8 Relativization barrier (Baker–Gill–Solovay) in an oracle stack-machine model
  - [x] M8a oracle `B` with `P^B ⊊ NP^B` (diagonalisation)
  - [x] M8b oracle `A` with `P^A = NP^A` (self-referential padded oracle)
- [x] M9 Natural proofs barrier (Razborov–Rudich), with PRF security as an explicit hypothesis
- [x] M10 Algebrization barrier (Aaronson–Wigderson) with multiquadratic extensions over prime fields
- [x] M15 Algebrization barrier extended to multiquadratic extensions over all finite fields (`Fld q`, `IsExtension.exists_poly`)
- [x] M16 Goldreich–Levin: the inner product is a hardcore bit of any one-way function (concrete `goldreich_levin`, asymptotic `OWF.hardcore_ip`)
- [x] M17 One-way permutations ⇒ secure PRGs (Blum–Micali–Yao) ⇒ natural-proofs barrier (`no_natural_property_of_owp`)
- [x] M18 Nisan–Wigderson generator: average-case hardness + polynomial designs ⇒ pseudorandom bits (`nw_secure`, `nw_poly_secure`)
- [x] M19 Average-case hard functions exist (Chernoff-type counting, `exists_avgHard`, `exists_avgHard_explicit`, `exists_nw_secure`)
- [x] M20 Adleman: randomized circuits can be derandomized non-uniformly (`adleman`, circuit form of BPP ⊆ P/poly)
- [x] M21 official-style `BPP` (Mathlib TM2 verifier on `w#r`) and `BPP ⊆ P/poly` (`inPPoly_of_inBPP`)
- [x] M22 Sipser–Gács–Lautemann, circuit form (`sipser_gacs_lautemann`, `sipser_gacs_lautemann_third`): BPP-type circuits have Σ₂ and Π₂ circuit formulas
- [x] M23 Valiant–Vazirani isolation (`isolation`, `valiant_vazirani`): random hashing leaves a unique solution with probability ≥ 1/8
- [x] M24 official `P ⊆ NP` without the composition hypothesis (`p_subset_np`, hand-built projection-then-decide TM2 machine) and official `P ⊆ BPP` (`inBPP_of_inPolynomialTime`)
- [x] M25 polynomial-time `TM2` computability is closed under composition (`comp`), so every upstream result conditional on `PolynomialTimeComputableComposition` holds unconditionally
- [x] M26 official `BPP ⊆ Σ₂ᴾ` over `Bool` (`bpp_subset_sigma2`): Sipser–Gács–Lautemann with amplification, the inner predicate decided by a stack program written in a small structured language (`Pnp/Oracle/Struct.lean`), transferred to the official nested pair encoding by a symbol-wise homomorphism TM2 machine (`inPolynomialTime_of_code`)
- [x] M27 SAT ∈ NP for the official class (`Pnp.CookLevin.sat_in_np`): dense CNF formulas over `{pos, neg, zero, sep}` (`SATLang`, clause form `clauses_sat_iff`), verified by a structured stack program in time `(n+2)^4` on all inputs; first half of Cook–Levin
- [x] M28 Tseitin transformation (`Pnp.CookLevin.tseitin_sat_iff`, `length_tseitin_le`): every B₂ circuit `C` with `n` inputs and `s` gates maps to a dense CNF `tseitin C` (one variable per wire, ≤ 4 clauses per gate) that is satisfiable iff `C` is, of length ≤ `(4s+1)(n+s+1)`; combinatorial core of Cook–Levin NP-hardness (uniformity of the map not yet proved)
- [x] M29 Cook–Levin, non-uniform form (`Pnp.CookLevin.np_circuit_form`, `cook_levin_nonuniform`): every official NP language has, per input length `n`, a polynomial-size circuit on input + certificate bits, hence a polynomial-size clause list `φ_n` with `w ∈ L ↔ SAT(φ_n ∧ input = w)` (Tseitin with fixed inputs, `sat_fixed_iff`); uniformity (poly-time computability of `n ↦ φ_n`) still open in this repo
- [x] M11 Connect the oracle model to the official classes
  - [x] M11a `P ∅ ⊆ P` (official, alphabet `Bool`)
  - [x] M11b `NP ∅ ⊆ NP` (official)
  - [x] M11c `P ⊆ P ∅` (simulate Mathlib TM2 machines by stack programs), hence `NP ∅ ⊄ P ∅ ⇒ NegativeBranch`
  - [x] M11d `NP ⊆ NP ∅`, hence `NP ∅ = NP` and (official `P = NP` over `Bool`) ↔ `P ∅ = NP ∅`

Known barriers (relativization, natural proofs, algebrization) mean none of these
techniques can by themselves separate P from NP. M8 formalizes the first of them, M9 the second and M10 the third.
